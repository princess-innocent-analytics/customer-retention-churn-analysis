# Customer Retention & Churn Analysis (SQL)

## Project Overview
This project analyses customer retention and churn using e-commerce transaction data.
Churn was defined as customers who had no purchases for 180 days or more.

## Tools Used
- SQL (SQLite)
- DB Browser for SQLite
- Excel (CSV outputs)
- Microsoft Word (Insights & Recommendations)

## Methodology
- Explored and cleaned transactional data
- Analysed customer behaviour (orders, activity, repeat customers)
- Calculated last purchase date per customer
- Computed days since last purchase
- Classified customers as Active or Churned
- Exported final churn dataset for reporting

## Key Insights
- A significant number of customers were inactive for over 180 days
- Active customers showed more recent and consistent purchasing behaviour
- Churn analysis highlights opportunities for targeted re-engagement

## Outputs
- SQL scripts (Day 1–Day 3)
- Customer-level churn dataset (CSV)
- Business insights and recommendations (Word document)
